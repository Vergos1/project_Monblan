## About

Monblan is a single-page Instagram analytics dashboard for the `monblanproject` account. The page displays account stats, a scrollable post feed with likes and comments per post, and a date range picker for filtering content by period.

## Features

- **Account stats** — posts count, followers and following displayed in the header
- **Post feed** — grid of posts with like and comment counters per item
- **Date range filter** — from/to date picker using Duet Date Picker web component
- **Load more** — button to load additional posts
- **SCSS architecture** — variables, mixins, normalize, reset and component-based styles
